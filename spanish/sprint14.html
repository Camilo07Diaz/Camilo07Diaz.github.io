Análisis basado en datos para una aplicación de reseñas de libros: Proyecto de análisis con SQL

Analicé datos de libros, autores, editoriales, calificaciones y reseñas utilizando SQL para descubrir insights clave de negocio. El análisis se centró en publicaciones posteriores al año 2000, autores mejor valorados y usuarios más activos. Entregué métricas y conclusiones que respaldan la estrategia de producto de una aplicación de lectura competitiva.

Conclusiones

Este análisis en SQL reveló insights clave para una startup de aplicaciones de lectura: se identificaron 819 libros publicados después del año 2000, destacando títulos como “13 Little Blue Envelopes” con una calificación promedio de 4.67. Penguin Books lideró en número de publicaciones, mientras que J.K. Rowling/Mary GrandPré tuvieron los libros mejor valorados (promedio de 4.28 con más de 50 reseñas). Además, los usuarios más activos escribieron en promedio 24.33 reseñas, reflejando un alto nivel de compromiso, un factor clave para impulsar la retención y la estrategia de producto.
